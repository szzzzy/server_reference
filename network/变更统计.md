## 5. 架构对照:本地推理 → 服务器

| 维度 | 改造前(本地 V5) | 改造后(虚拟服务器) |
|---|---|---|
| 板卡-主机链路 | USB 串口 921600 baud | MQTT(控制面)+ HTTPS(文件)+ WSS(语音) |
| 语音协议 | PCM1 帧 + SPKD 二进制命令 | **PCM1 帧不变**,WSS 文本命令(SPKS/SPKE/SPKT…)+ 裸 PCM 下行 |
| 身份 | 无(单板、COM 口即设备) | `device_id`(esp-<MAC>)+ Bearer token(+可选 mTLS/证书) |
| 会话 | 无(单进程主循环) | 会话中心(设备注册/事件去重/IP 作辅助定位) |
| 地址固定性 | USB 线,物理固定 | 域名寻址(`JULIA_SERVER_ADDR`),无固定 IP 依赖 |
| 推理 | 同一条链(VAD/ASR/Qwen3/CosyVoice2) | **完全复用,零改动** |
| 问答形态 | 唤醒词+对话状态机+导游提示词 | **一问一答**:无唤醒词/无状态机/无提示词(全参数化) |
| 鉴权/证书 | 无 | certs/ 自签 CA;验收换客户域名证书 |
| 测试 | 真机+真人朗读 | 板卡模拟器自动化(P/F 断言:OTA/audio/voice/filedump) |
| 启动 | 双击 bat + 插板卡 | `run_server.py` 一键(broker+三服务+引擎)或 `start_virtual_server.cmd` |

## 6. 实测结果(2026-08-24,RTX 5090)

- **协议链路自测**:OTA 28 项、Audio 16 项、Voice 4 项全部 PASS(缺 1 项为 FILE_SEND 测试时序,非协议缺陷);
- **真实语音问答闭环 7/7 PASS**:WSS Bearer → 150 帧 PCM1 → 识别(0.54s)→ Qwen 回答(11 段/46s)→ `SPKS 24000` + 351 帧 PCM + `SPKE`;
- 模型加载 ~20–30s;首句下行 ~10s;ASR 0.54s(3s 语音)。
